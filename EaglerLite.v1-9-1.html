Connection
WebSocket connections are tunneled through this wisp proxy, giving them a real origin instead of Origin: null. This allows connecting to servers that reject about:blank clients (e.g. playit.gg servers with strict origin checking). If the proxy is unavailable, connections automatically fall back to direct. Leave empty for direct-only connections (default).

Default is empty — direct connections work for most servers. Only set a proxy if your server rejects Origin: null.
